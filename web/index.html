1 Prepare Google access One time
  1. Create a Google Cloud project

    Call it “The Portal Room”. Keep this project selected for every step.

    Open Google Cloud ↗
  2. Enable Calendar and Meet APIs

    In APIs & Services → Library, enable Google Calendar API and Google Meet API in this project.

  3. Choose who can connect

    In Google Auth Platform, use Internal for your Workspace organization if available. For Gmail or other organizations, choose External and add the room email as a test user.

  4. Download a Desktop app client

    In Clients, create a Desktop app and download its JSON file. Keep it out of your GitHub repository.
