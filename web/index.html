ONE-TIME SETUP

Make it automatic.

1

Connect the room calendar

The controller reads meeting invitations. Your Google password stays with Google.

Set up Google access
  1. Create your own project in Google Cloud Console.
  2. Enable Google Calendar API and, for drop-ins, Google Meet API in that same project.
  3. Configure the Google Auth Platform consent screen. Workspace organizations may use Internal for their own users. Gmail and cross-organization setups use External; add your room email as a test user during setup.
  4. Create a client of type Desktop app, download its JSON, and import it below.
  5. Connect the exact Google account you saved for this room. Sign into the separate room Chrome profile with the same account.
  6. Before unattended use, move an External app to Production and check Google's verification requirements. Testing grants for Calendar/Meet are short-lived. See docs/google-setup.md in your fork for the complete guide and recovery steps.

The Portal reads Calendar events. It does not read Gmail or create email accounts. Never commit the downloaded JSON to GitHub.

2

Sign in to room Chrome

This browser profile is separate from your everyday Chrome. Sign in as your Google account, then return here to check the account.

3

Connect room devices

Connect your camera, microphone, and speaker. In Google Meet, select your room devices for camera, microphone, and speakers, and allow Chrome access. Then send the room a short test invitation.

Until devices and permissions are ready, the controller waits on the meeting preview instead of claiming it joined.
