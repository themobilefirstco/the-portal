# Room hardware

Use an Apple Silicon or supported Intel Mac mini running a macOS version compatible with the pinned Node runtime and current Chrome. A logged-in desktop session is required; this is not a headless Linux appliance.

- TV or monitor with an appropriate HDMI/USB-C connection and a stable mount.
- USB webcam with a field of view appropriate to the table.
- USB conference speakerphone with echo cancellation, or a tested microphone/speaker combination.
- Wired Ethernet where possible, reliable power and enough USB ports or a powered hub.
- Keyboard and pointing device for initial setup and recovery.

No specific brand is required. Test the actual camera, microphone, speaker output and echo with a remote participant before leaving the room unattended. Check wake/sleep behavior, display reconnection and USB device recovery after reboot. The controller cannot prove acoustics or camera framing from software alone.
